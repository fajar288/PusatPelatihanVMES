# PPTI VMES ITMS: Master Task List

> Sumber: (1) reverse engineering `https://pusatpelatihan.id/` (WordPress, tema custom `ppti-vmes`), (2) PRD v1.0 "PPTI VMES Integrated Training Management System" (3 Nov 2026).
> Target stack: **Next.js (App Router, TypeScript) + Laravel (REST API) + PostgreSQL + Tailwind**.
> Dokumen pendukung: [docs/PRD.md](docs/PRD.md) (teks PRD), [docs/reference/](docs/reference/) (CSS/JS/HTML asli), [docs/screenshots/](docs/screenshots/) (tangkapan layar tiap section).

## 0. ATURAN WAJIB (baca sebelum mengerjakan task apa pun)

1. **UI/UX publik WAJIB "plek ketiplek" dengan pusatpelatihan.id.** Jangan mendesain ulang. Sumber kebenaran visual adalah:
   - `docs/reference/theme.style.css` → seluruh nilai warna, radius, shadow, spacing, font-size, breakpoint. **Salin nilainya apa adanya.**
   - `docs/reference/home.body.html` → struktur DOM beranda (urutan section, class, teks, ikon).
   - `docs/reference/theme.main.js` → perilaku interaktif (slider, counter, paginasi, lightbox, header shrink, filter katalog).
   - `docs/reference/icons-sprite.svg` → 39 ikon SVG (stroke 2, lucide-style). Pakai ikon ini, bukan library lain.
   - `docs/screenshots/*.jpg` → acuan visual akhir, bandingkan side-by-side.
2. Di frontend, CSS tema asli di-port 1:1 ke `frontend/src/styles/theme.css` dengan **nama class yang sama** (`.hd`, `.hero2`, `.cc`, `.jr`, dst). Komponen React hanya membungkus markup asli. Tailwind dipakai untuk halaman **baru** (portal member, trainer, admin) yang tidak ada di website lama, tetap memakai token warna yang sama.
3. Font: **Plus Jakarta Sans** 400/500/700/800 (Google Fonts, via `next/font/google`). Tidak ada font lain.
4. Semua teks copy (judul, deskripsi, CTA) dipakai apa adanya dari website lama kecuali yang jelas placeholder WordPress ("Hello world!", "Contoh konten...").
5. Gambar hero/galeri di website lama di-hotlink dari situs pihak ketiga (bukan milik PPTI). Dipakai URL yang sama agar tampilan identik. ~~Wajib diganti dengan foto PPTI sendiri sebelum go-live~~ - **keputusan atasan 2026-11-16: hotlink dibiarkan**. Foto yang sudah tidak tampil diganti dengan foto berlisensi bebas (mis. Unsplash) yang masih satu konsep, tanpa mengubah tata letak (lihat §1.9).
6. Data dummy (kursus, jadwal, testimoni, partner) disimpan di `frontend/src/data/*.ts` dan nanti diganti dengan fetch ke API Laravel tanpa mengubah komponen.

### 1.11 Perilaku UX yang harus dipertahankan

- Header mengecil saat scroll; hamburger hanya muncul kalau nav tidak muat.
- Semua CTA "Hubungi Kami / Konsultasi / Daftar" membuka WhatsApp di tab baru dengan teks prefill (`?text=`), daftar per jadwal menyertakan nama + tanggal.
- Slider kursus autoplay & pause saat interaksi; partner & testimoni geser manual.
- Counter statistik animasi sekali saat masuk viewport.
- Testimoni: klik kartu kecil menukar featured.
- Galeri: lightbox.
- Katalog: cari (substring pada `data-q`), filter kategori & mode, urutkan (terbaru, populer, harga rendah/tinggi, A-Z), teks "Menampilkan N training", pesan kosong "Tidak ada hasil yang cocok. Coba kata kunci atau filter lain."
- Jadwal terdekat: paginasi 7 baris.
- Fokus keyboard: outline 3px green.

- Roadmap 5 tahap **5I.5 Asisten Belajar LMS** (branch `feat/ai-lms-assistant`). Kerangka 5G (`LearningAssistantService`, `LearningAssistantShellTest`, config `ai.assistant`) **diganti** asisten sungguhan; flag tetap `AI_CHATBOT_ENABLED` (sekarang juga butuh `AI_ENABLED=true` + `ANTHROPIC_API_KEY`, dicek lewat `AiGovernance`). **`AiLearningAssistantService`**: hanya peserta yang lolos `LmsService::authorize` (aturan akses LMS yang sama, 403 dengan alasan) yang bisa bertanya; sumber = lesson terbit di modul terbit, sudah dibuka (`available_from`), tipe teks/dokumen/video/tautan dengan isi teks (kuis dan tugas **tidak** dipakai agar tidak membocorkan jawaban yang dinilai); HTML materi diubah ke teks polos dan disaring dari email/telepon/NIK; pertanyaan juga disaring. Ke Claude hanya dikirim materi + pertanyaan (tanpa nama, nilai, progres, kode kelas). Materi dikirim sebagai **dokumen dengan citations** (titik cache setelah dokumen terakhir, prompt sistem ikut di-cache; tanpa structured output karena tidak bisa digabung citations); batas panjang `AI_LMS_ASSISTANT_MAX_MATERIAL_CHARS` (200 ribu karakter) mendahulukan lesson yang sedang dibuka dan mencatat `material_truncated`. Jawaban: segmen bernomor sumber [n] + daftar sumber (lesson, modul, kutipan maks. 2); penanda `[TIDAK_ADA_DI_MATERI]` atau jawaban **tanpa kutipan** = tidak terjawab, teks model tidak ditampilkan/disimpan, diganti pesan baku + tautan forum diskusi (lesson atau course); course tanpa materi teks = tidak terjawab tanpa memanggil model. Setiap jawaban = insight `lms_assistant` (subjek enrollment, tanpa organization_id, langsung tampil, kedaluwarsa `AI_INSIGHT_TTL_DAYS`), referensi = course, enrollment, lesson + hash isi. Batas **`AI_LMS_ASSISTANT_PER_USER_DAILY`** (20) per peserta per hari (429 `ai_limit`) di samping batas harian use case; limiter `ai-assistant` 6/menit. Galat/penolakan model = 503 `ai_failed` (tercatat di pemakaian, tanpa insight); fitur mati/dijeda = 503 `ai_unavailable`. Kontrak model: `ChatModel` menerima isi pesan berupa blok, `ChatReply`/`AiResult` membawa `segments` (teks + kutipan, dinormalkan `AiText`), `AnthropicChatModel` membaca `citations` blok teks; `FakeChatModel` bisa membalas segmen bersitasi. API: `GET /me/assistant` (status, kuota, course + lesson sumber; `?brief=1` tanpa daftar course), `GET /me/assistant/messages[?course=]` (riwayat sendiri + umpan balik), `POST /me/assistant/messages` (`course`, `question` maks. 1000, `lessonId` opsional). `AiInsightAccess`: jawaban hanya untuk peserta pemilik enrollment (+ staf AI), trainer/peserta lain 404.
